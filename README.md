# claude

Personal repository for Claude Code work.

## Contents

- **`youtube-shorts/`** — full design package for the user's YouTube Shorts channel (AI-animated shorts on trending topics, modeled on the Afterhour Theory channel):
  - `research/` — channel analysis of Afterhour Theory (8 shorts + trending-topic method) + current trending topic research + reference thumbnails
  - `design/` — the full video package: concept, title, script, 13-scene storyboard, captions, thumbnail design, toolchain, metrics
  - `memory/` — Claude's saved memories about this project
  - `upload/` — scripts used to try uploading to Google Drive (Drive needs your own OAuth key; GitHub is easier)
  - `shorts-design-package.zip` — zipped copy of the whole package
